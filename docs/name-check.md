# Cairnspan Name Check

Last checked: 2026-07-11

## Owner Decision

Use **Cairnspan** as the selected working public name and `cairnspan` as the
repository, skill, package, and runtime slug. The private-alpha source
migration was authorized on 2026-07-12 and uses a clean break across display
text, paths, runtime defaults, schemas, tests, receipts, protocol markers, CI,
and environment prefixes. Historical ignored runtime receipts are preserved
in place and are not a supported compatibility surface.

A cairn marks a route that another traveler can follow; a span is a bounded
crossing between separate endpoints. The metaphor fits a parent-controlled
handoff that declares limits, crosses one provider boundary, returns evidence,
and closes only after validation.

Suggested one-line description:

> Cairnspan by Rahul K Labs: bounded cross-agent handoffs with receipts.

The cairn/span metaphor must not be described as a security, cryptographic,
truth, confidentiality, or tamper-proof guarantee.

## Point-In-Time Checks

Exact searches for `Cairnspan` / `cairnspan` on 2026-07-11 found no obvious
same-name software or AI product. Focused GitHub, GitLab, npm, and PyPI web
searches returned no indexed exact match. Broad web and trademark smoke
searches surfaced spelling noise around `CairnsPlan`, not an exact Cairnspan
brand.

These are smoke checks, not legal clearance, registry guarantees, namespace or
domain reservations, or proof that an unindexed/private use does not exist.
Before the next package release or broader public naming claim, re-run direct
GitHub, GitLab, npm, PyPI, domain/RDAP, and relevant trademark-class checks and
reserve the selected namespaces separately.

## Rejected Or Superseded Names

Do not revive the former OAuth-led prototype name publicly. Authentication is
an implementation detail, and leading with it creates avoidable provider-policy
and credential-brokering implications even though Cairnspan launches separately
authenticated local clients and does not broker tokens.

Do not use bare **Parley**. It is crowded in the same software and AI
neighborhood:

- <https://parley.sh/> is a private multi-model deliberation product;
- <https://www.parley.run/> is an AI-agent negotiation platform;
- Google Play lists `Parley: Multi-Agent AI Chat`;
- npm and PyPI already use `parley`; and
- older software and a separate cross-agent skill also use the name.

**RouteLatch** remains a viable historical alternate with stronger recorded
package/domain smoke-check evidence, but it is superseded by the owner's
Cairnspan selection. **Envoyspan** remains an unselected provisional alternate.

Other candidates rejected during the earlier pass include `Relaymark`,
`Runmark`, `Taskrail`, `Routeframe`, `Scopewright`, `Threadmark`, `Workspan`,
`Runframe`, and `Workbound` because active software, AI, or company uses were
found.

## Migration Outcome

The migration inventory covers every display name, skill path, runtime default,
environment prefix, schema-facing receipt name, protocol marker, script, test,
CI entry, example, fixture, and document. The compatibility policy is a clean
break: historical private receipts remain ignored, but new runs do not read or
write legacy runtime names.

The repository is now source-public alpha, and PyPI `0.1.0` exists without a
matching Git tag or GitLab Release. The exact-name, namespace, domain,
package-registry, and legal trademark review must still be repeated immediately
before the next package release or broader public naming claim; the 2026-07-11
smoke check is not a reservation.
